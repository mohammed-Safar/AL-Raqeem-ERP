# Raqeem Arabic glossary — المسرد الموحد للمصطلحات

Every Arabic string in `ar.csv` follows these terms. To change a term everywhere,
change it here first, then search-and-replace it in `ar.csv`.

`ar.csv` overrides the Arabic shipped with Frappe and ERPNext, because raqim_sales is
installed after them. Strings added through the Translation doctype override this file.
